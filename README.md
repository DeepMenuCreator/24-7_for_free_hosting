# FakePlayer24-7

Плагин для Paper 1.21.4, который создаёт невидимого фейкового игрока, чтобы сервер считался "онлайн" 24/7 на бесплатных хостингах, которые отключаются при отсутствии игроков.

## Что делает плагин

- Создаёт **настоящего** игрока на уровне сервера (NMS `ServerPlayer`)
- Сервер видит его как реального онлайн-игрока (`/list`, `Bukkit.getOnlinePlayers()`)
- Игрок находится в отдельном мире `Server` — никто его не видит
- **Невидим в табе** и в игре для всех реальных игроков
- **Нет сообщений** о входе/выходе в чате
- Автоматически пересоздаётся, если исчезает
- Неуязвим, летает, не голодает

## Требования

- **Paper 1.21.4** (или Purpur)
- **Java 21**

## Сборка

Локально:
```bash
gradle build
```

Или используй GitHub Actions — workflow уже настроен в `.github/workflows/build.yml`.

## Установка

1. Скопируй `FakePlayer24-7-1.0.0.jar` в папку `plugins/`
2. Запусти сервер
3. Плагин автоматически создаст мир `Server` и заспавнит бота `Server24_7`

## Проверка

```
/list
```

Должен показывать 1 игрока, даже если на сервере никого нет.

## Важно

- Бот создаётся через NMS. Это внутренний API Paper/Minecraft, который может измениться в других версиях.
- Плагин рассчитан **только на 1.21.4**.
- Некоторые хостинги проверяют активность не только по `onlinePlayers`, но и по реальному трафику. Этот плагин решает только первую проблему.
